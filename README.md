# Track My DSA

A personal DSA progress tracker made using HTML, CSS, and JavaScript.  
It helps you stay consistent with your practice by logging problems, tracking your streak, and planning daily study sessions.

---

## Features

- Add solved problems with date, topic, difficulty, and notes
- See your 7-day activity streak
- Track topic-wise progress with a heatmap (using Chart.js)
- Get XP for every question and level up
- Write reflections on last 7 problems
- Use a planner that suggests topics based on your available time
- Light/Dark Mode switch for better comfort

---

## Tech Used

- HTML + CSS + JavaScript
- Chart.js for graphs
- localStorage to save data
- GitHub Pages for deployment
